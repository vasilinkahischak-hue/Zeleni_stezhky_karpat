# Зелені стежки Карпат — ЛР №9

Це підготовлена для тестування версія сайту після лендингу (ЛР №7) і GitHub (ЛР №8).

## Що залишилось незмінним
- 11 HTML-сторінок, 6 туристичних маршрутів.
- Дизайн-система Tailwind та колірна палітра; Hero на початковому місці.
- Відео YouTube, карта Українських Карпат, калькулятор і демонстраційне бронювання.

## Що виправлено
- Форматування HTML (4 пробіли), структурні коментарі, групування CSS-модулів.
- Структура списку в `about.html`, узгодження цін у рекомендованих картках.
- У `about.html` показано 6 маршрутів; видалено зайву JS-логіку фільтра «Тип походу».
- Додано preload для основного фонового зображення Hero.
- Додано smoke-тести Chromium для DOM/JS, збережено структурний аудит.

## Підготовка до запуску

У цьому архіві **не було** графічних файлів попередніх лабораторних. Не видаляйте `assets/images` і `assets/icons` у своєму чинному репозиторії! Для коректного відображення сайту потрібні 27 файлів, назви наведені у `assets/README.md`. Перенесіть у робочу папку поточні файли із свого GitHub-репозиторію разом із папкою `assets`.

Сайт — навчальний прототип. Він не приймає оплату чи реальні заявки.

## Локальна перевірка

```bash
python tests/check_static.py
python tests/check_functional.py
node --check js/site.js
```

Для `check_static.py` потрібен BeautifulSoup, для `check_functional.py` потрібні Python Playwright та Chromium. Не слід вважати ці перевірки заміною онлайн-валідаторів W3C, Lighthouse та ручної перевірки на справжніх пристроях.
