# Зелені стежки Карпат

Вебсайт екологічного туризму Українськими Карпатами для навчального проєкту.

**Відновлена верстка:** сайт використовує локальні `css/tailwind-built.css` і `css/style.css` замість залежності від зовнішнього Tailwind CDN. Усі сторінки, маршрути, калькулятор, валідація форми й вибір спорядження збережені.

Для перенесення в поточний репозиторій відкрийте **`ВАЖЛИВО_ЯК_ОНОВИТИ.md`**.

Сайт містить **6 маршрутів**. Бронювання демонстраційне, без реальних платежів і надсилання заявки.
