# Зелені стежки Карпат — ЛР №11

## Основа
Використано архів ЛР №10 та останнє оновлення темної теми. Новий функціонал не змінює існуючі `js/site.js`, `js/validation.js`, `js/plugins.js` та тарифи бронювання.

## Новий віджет

- `index.html#trip-budget` — нова секція «Плануйте бюджет походу заздалегідь».
- `data/widget-data.json` — **шість маршрутів** із незміненими базовими цінами й окремі демонстраційні тарифи.
- `js/widget.js` — ізольована логіка Vanilla JS із `fetch`, перевірками полів, `textContent`, `requestAnimationFrame` і повідомленням про недоступність JSON.
- `css/widget.css` — адаптивний дизайн з підтримкою світлої та темної тем.
- `css/theme.css` і 11 HTML-сторінок — компактний мобільний хедер: іконка перемикача, логотип без довгого тексту, меню, менша кнопка «Забронювати».

## Важливо при встановленні

1. **Зробіть резервну копію робочого проєкту** `Zeleni_upload_LR10`.
2. Розпакуйте архів з оновленими файлами до кореня локального проєкту, підтвердивши заміну HTML та `css/theme.css`.
3. **Не видаляйте** наявну папку `assets/`: ваші фото, темні SVG, лого спорядження тощо повинні залишитися. Архів містить лише змінений код, не фотографії.
4. Запустіть сайт через **Live Server**. `file://` не підходить для `fetch` локального JSON.
5. Відкрийте `index.html#trip-budget`. У DevTools → Network перевірте, що `data/widget-data.json` повертає **200**.
6. Змініть маршрут, кількість людей, дні, транспорт, дві опції — сума має перераховуватися автоматично.
7. Перевірте випадки: порожнє поле, `0`, `-5`, `9999999999999999`, `2.5`, буква `e`, неправильний select через DevTools, вимкнений JSON (404). Для помилки — повідомлення під полем і сума «—», без `NaN` або від'ємних підсумків. Дробові дні округлюються вгору; дробові учасники заборонені.
8. Перевірте мобільний хедер на 320, 375, 768, 1024, 1280, 1440 px, світлу й темну теми та попередні функції сайту (бронювання, форма, Swiper, Fancybox, Typed.js).
9. Тільки після локальної перевірки зробіть Git commit + push до **наявного** репозиторію; Vercel має автоматично створити новий deployment.

### Приклад Happy Path
Піп Іван / 2 учасники / 3 дні / харчування / спорядження / трансфер з Івано-Франківська:

- Тур: 2400 × 2 = **4800 грн**
- Харчування: 220 × 2 × 3 = **1320 грн**
- Спорядження: 150 × 3 = **450 грн**
- Трансфер: **300 грн**
- Загалом: **6870 грн**

Початкова ціна маршруту не змінюється при коригуванні кількості днів для додаткових витрат. Зміну тривалості самої туристичної програми узгоджують з організатором.

### Автоматизовані тести

```bash
node tests/test_lr11_widget.cjs
```

Результат під час підготовки: **22 із 22** юніт-тестів пройдено. Синтаксис JS перевірено через `node --check`. Браузерний інтерфейс та Vercel-публікацію слід перевірити на вашому комп'ютері (у середовищі підготовки Chromium блокував локальний сайт).

### Git без конфліктів
Виконуйте команди **у вашій поточній робочій Git-папці** (не в архіві й не в старій `v3`):

```bash
git status
git add -A
git commit -m "feat: add trip budget planner with defensive QA"
git push origin main
```

Не використовуйте `--force`.
